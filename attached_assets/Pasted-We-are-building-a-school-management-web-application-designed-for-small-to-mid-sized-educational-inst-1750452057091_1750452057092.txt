We are building a school management web application designed for small to mid-sized educational institutions. The system should support the core operations of academic administration, student progress tracking, and subject-level collaboration. Here's a breakdown of the intended features and structure:

🎓 Core Functionalities:
1. Student Registration & Enrollment
Students are assigned unique student numbers upon registration.

Each student is enrolled into a specific level (e.g., Level 1, Level 2, etc.), which acts as a combination of class/grade and semester.

Levels are customizable — the institution should be able to add or remove levels to accommodate educational expansion.

2. Level Progression
Each level has a 6-month duration.

Upon completion, students should be able to progress automatically or manually to the next level.

Graduation occurs after the final level (e.g., Level 4).

📚 Academic Management:
3. Subjects & Grading
Each level can have multiple subjects assigned to it.

Subjects can be added or removed per level.

Admins (e.g., teachers) can enter grades/scores for students within specific subjects.

The system should maintain academic records per student per subject, with historical data if needed.

👥 User Roles:
4. Role-Based Access
Students should have limited access:

View their profile

View enrolled subjects

View grades

Participate in forums

Admins (e.g., Teachers/Managers) should:

Manage students, subjects, levels

Enter grades

Track student progress

View/manage forums

💬 Communication Tools:
5. Forums & Subject Chats
A general forum for school-wide announcements or discussion.

Each subject should have its own simple chat space or forum to allow students and teachers to discuss or post relevant messages.

✅ Notes:
The system should be lightweight and user-friendly, without unnecessary complexity.

It can start simple but should be scalable for future feature additions.

Built with a modern tech stack (React + Express or similar) and hosted on a platform like Replit or Render.
